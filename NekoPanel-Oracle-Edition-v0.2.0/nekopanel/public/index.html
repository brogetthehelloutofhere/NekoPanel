CONNECTIVITY

RCON setup

Checking

RCON unlocks live command execution and online player tools. Keep the RCON listener bound to localhost and never expose its port to the public internet.

  1. Set enable-rcon=true in server.properties.
  2. Choose a long, unique rcon.password.
  3. Set RCON_PASSWORD in /etc/nekopanel/nekopanel.env.
  4. Restart Minecraft and NekoPanel services.
